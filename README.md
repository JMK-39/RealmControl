# Realm Control

## English

Realm Control provides visual tools for world blocks, structure and biome generation, beacon areas, and teleport authorization.

### See a published courtyard generate in fresh terrain

Open the generation rules for a published structure and check which biomes can generate it. This courtyard measures 23 × 8 × 19 blocks. In a fresh Overworld, Minecraft’s terrain generator produced it in a plains biome under those rules.

![Continuous Minecraft recording opening a published courtyard’s generation rules and flying around the courtyard that generated in new plains terrain](https://raw.githubusercontent.com/wiki/JMK-39/RealmControl/media/tutorials-20261126/generation-en.gif)

### Pick and edit an entity in a 3D structure draft

Drag to turn the courtyard and scroll closer. Click the armor stand in the model to open its properties, enter a new name and save it to the structure draft.

![Continuous gameplay rotating a courtyard, selecting an armor stand in 3D and saving its new name](https://raw.githubusercontent.com/wiki/JMK-39/RealmControl/media/tutorials-20261126/en.gif)

[Editor guide](https://github.com/JMK-39/RealmControl/wiki/Structures)

- Generation bans, fixed replacements, and weighted replacements.
- Structure/biome rules with 3D structure previews, and configurable beacon coverage.
- A structure editor that turns a building in the world into a data pack structure generating in new chunks.
- Teleport-use limits and timed authorization.

Supports Minecraft **1.20.1 / Forge 47.4.2+**, **1.21.1 / NeoForge 21.1+** (validated with 21.1.252) and **26.1.2 / NeoForge 26.1.2+** (validated with 26.1.2.112). Requires **Java 17** on 1.20.1, **Java 21** on 1.21.1, **Java 25** on 26.1.2, and **KineticCore 26.11.24+** matching the Minecraft/loader. Install required mods on the server and connecting clients.

Optional: Jade 11+ on Forge or 15+ on NeoForge for beacon information.

## 简体中文

Realm Control 提供世界方块、结构与群系生成、信标区域和传送授权的可视化管理工具。

### 看已发布的庭院在新区块自然生成

打开已发布结构的生成规则，查看哪些群系可以生成它。这座庭院的长、高、宽为 23 × 8 × 19 格。新主世界开始生成时，游戏按这些规则把庭院生成在了平原。

![打开已发布庭院的生成规则，再绕飞查看庭院在全新平原地形中自然生成的连续游戏实录](https://raw.githubusercontent.com/wiki/JMK-39/RealmControl/media/tutorials-20261126/generation-zh.gif)

### 在 3D 草稿里直接点选和编辑实体

按住左键转动院子，滚动滚轮拉近视角。直接点模型里的盔甲架，右侧就会切到它的属性。在这里输入「庭院守望者」，保存后名称就写进了结构草稿。

![转动院子、拉近镜头、点选盔甲架并保存新名称的连续实录](https://raw.githubusercontent.com/wiki/JMK-39/RealmControl/media/tutorials-20261126/zh.gif)

[编辑器使用指南](https://github.com/JMK-39/RealmControl/wiki/%E7%BB%93%E6%9E%84%E7%94%9F%E6%88%90)

- 方块生成禁用、固定替换与加权替换。
- 结构、群系规则（带结构 3D 预览）及可配置信标区域。
- 结构编辑器：把世界里的建筑做成在新区块中生成的数据包结构。
- 传送次数限制与限时授权。

支持 Minecraft **1.20.1 / Forge 47.4.2+**、**1.21.1 / NeoForge 21.1+**（验证使用 21.1.252）与 **26.1.2 / NeoForge 26.1.2+**（验证使用 26.1.2.112），必需 **Java 17**（1.20.1）、**Java 21**（1.21.1）、**Java 25**（26.1.2）和与 Minecraft、加载器匹配的 **KineticCore 26.11.24+**。服务端与连接的客户端均安装必需模组。

可选：Forge 使用 Jade 11+、NeoForge 使用 Jade 15+ 显示信标信息。
