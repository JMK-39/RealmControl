# Realm Control

> V1.0

## 简体中文

集中管理世界生成、结构、信标区域与传送权限。

### 核心功能

- 禁用、统一或按概率替换新生成地形中的指定方块。
- 调整结构启停、权重、间距与放置参数。
- 通过信标管理区块加载、配额与敌对生物生成保护。
- 为 `/tp` 和 `/teleport` 设置次数或限时授权。

### 使用

按 **F6** 打开 Realm Control。结构相关命令使用 `/kt world help`；传送授权使用 `/kt tpd help`。世界生成设置主要影响后续新区块，已生成区块不会自动重写，部分结构放置参数需要重启或重新进入世界。

### 前置依赖

必需：Forge 47.4.2+、KineticCore 26.9.20+；可选：Jade 11.0.0+。

## English

Centralizes world generation, structures, beacon areas, and teleport permissions.

### Features

- Ban, unify, or probabilistically replace blocks during new terrain generation.
- Configure structure enablement, weights, spacing, and placement.
- Manage beacon-driven chunk loading, quotas, and hostile-spawn protection.
- Grant count-based or time-limited access to `/tp` and `/teleport`.

### Usage

Press **F6** to open Realm Control. Use `/kt world help` for structure commands and `/kt tpd help` for teleport grants. Generation changes primarily affect new chunks; existing terrain is not automatically rewritten. Some structure placement settings require restarting or reopening the world.

### Requirements

Required: Forge 47.4.2+, KineticCore 26.9.20+. Optional: Jade 11.0.0+.
