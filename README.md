# Realm Control

## English

Realm Control provides visual tools for world blocks, structure and biome generation, beacon areas, and teleport authorization.

- Generation bans, fixed replacements, and weighted replacements.
- Structure/biome rules with 3D structure previews, and configurable beacon coverage.
- A structure editor that turns a building in the world into a data pack structure generating in new chunks.
- Teleport-use limits and timed authorization.

Supports Minecraft **1.20.1 / Forge 47.4.2+**, **1.21.1 / NeoForge 21.1+** (validated with 21.1.252) and **26.1.2 / NeoForge 26.1.2+** (validated with 26.1.2.112). Requires **Java 17** on 1.20.1, **Java 21** on 1.21.1, **Java 25** on 26.1.2, and **KineticCore 26.11.4+** matching the Minecraft/loader. Install required mods on the server and connecting clients.

Optional: Jade 11+ on Forge or 15+ on NeoForge for beacon information.

## 简体中文

Realm Control 提供世界方块、结构与群系生成、信标区域和传送授权的可视化管理工具。

- 方块生成禁用、固定替换与加权替换。
- 结构、群系规则（带结构 3D 预览）及可配置信标区域。
- 结构编辑器：把世界里的建筑做成在新区块中生成的数据包结构。
- 传送次数限制与限时授权。

支持 Minecraft **1.20.1 / Forge 47.4.2+**、**1.21.1 / NeoForge 21.1+**（验证使用 21.1.252）与 **26.1.2 / NeoForge 26.1.2+**（验证使用 26.1.2.112），必需 **Java 17**（1.20.1）、**Java 21**（1.21.1）、**Java 25**（26.1.2）和与 Minecraft、加载器匹配的 **KineticCore 26.11.4+**。服务端与连接的客户端均安装必需模组。

可选：Forge 使用 Jade 11+、NeoForge 使用 Jade 15+ 显示信标信息。
