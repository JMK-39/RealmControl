# Realm Control

## English

Realm Control provides visual tools for world blocks, structure and biome generation, beacon areas, and teleport authorization.

### Change a block and place the edited building

Open the courtyard draft, click a stone brick in the 3D view and replace it with a gold block. The recording follows the same block through saving and placement in the world.

### See a published courtyard generate in fresh terrain

Open the generation rules for a published structure and check which biomes can generate it. This courtyard measures 23 × 8 × 19 blocks. In a fresh Overworld, Minecraft’s terrain generator produced it in a plains biome under those rules.

![Continuous Minecraft recording opening a published courtyard’s generation rules and flying around the courtyard that generated in new plains terrain](https://raw.githubusercontent.com/wiki/JMK-39/RealmControl/media/bilingual-editors/RealmControl-generation/en.gif)

### Pick and edit an entity in a 3D structure draft

Drag to turn the courtyard and scroll closer. Click the armor stand in the model to open its properties, enter a new name and save it to the structure draft.

![Continuous gameplay rotating a courtyard, selecting an armor stand in 3D and saving its new name](https://raw.githubusercontent.com/wiki/JMK-39/RealmControl/media/bilingual-editors/RealmControl/en.gif)

[Editor guide](https://github.com/JMK-39/RealmControl/wiki/Structures)

- Generation bans, fixed replacements, and weighted replacements.
- Structure/biome rules with 3D structure previews, and configurable beacon coverage.
- Open **Structure library** to edit a layout from Minecraft or another mod. Click a block in the 3D editor to change its state, or select a container or entity to edit its properties. Use **Generate in world** to place the draft at a chosen coordinate. A separate publish option replaces the source layout for future generation.
- Publish a build up to 4096 × 4096 blocks from the visual structure editor. An entire town can share one rotation and ground level while its streets and buildings appear as players explore new chunks.
- Teleport-use limits and timed authorization.

Supports Minecraft **1.20.1 / Forge 47.4.2+**, **1.21.1 / NeoForge 21.1+** (validated with 21.1.252) and **26.1.2 / NeoForge 26.1.2+** (validated with 26.1.2.112). Requires **Java 17** on 1.20.1, **Java 21** on 1.21.1, **Java 25** on 26.1.2, and a matching **KineticCore 26.11.26+**. Install required mods on the server and connecting clients.

Optional: Jade 11+ on Forge or 15+ on NeoForge for beacon information.

Realm Control 提供世界方块、结构与群系生成、信标区域和传送授权的可视化管理工具。

### 在 3D 里点一块石砖，看它在世界里变成金块

打开庭院草稿，在模型上点中石砖，换成金块并保存。实录跟随同一块方块，直到改过的庭院放进世界。

### 在 3D 草稿里直接点选和编辑实体

按住左键转动院子，滚动滚轮拉近视角。直接点模型里的盔甲架，右侧就会切到它的属性。在这里输入「庭院守望者」，保存后名称就写进了结构草稿。

![转动院子、拉近镜头、点选盔甲架并保存新名称的连续实录](https://raw.githubusercontent.com/wiki/JMK-39/RealmControl/media/bilingual-editors/RealmControl/zh.gif)

[编辑器使用指南](https://github.com/JMK-39/RealmControl/wiki/%E7%BB%93%E6%9E%84%E7%94%9F%E6%88%90)

- 方块生成禁用、固定替换与加权替换。
- 结构、群系规则（带结构 3D 预览）及可配置信标区域。
- 打开**结构库**编辑原版或其他模组的布局，在 3D 视图中点方块改状态，或点容器和实体改属性。用**在世界中生成**将草稿放到指定坐标，也可以在发布时选择替换以后自然生成的原结构。
- 结构编辑器可把最大 4096 × 4096 格的建筑群发布到新区块中。整座城镇共用朝向和地基高度，玩家探索到哪一带，游戏就生成对应的街道和建筑。
- 传送次数限制与限时授权。

支持 Minecraft **1.20.1 / Forge 47.4.2+**、**1.21.1 / NeoForge 21.1+**（验证使用 21.1.252）与 **26.1.2 / NeoForge 26.1.2+**（验证使用 26.1.2.112），必需 **Java 17**（1.20.1）、**Java 21**（1.21.1）、**Java 25**（26.1.2）。KineticCore 需匹配 Minecraft 和加载器版本，**三个版本均至少为 26.11.26**。服务端与连接的客户端均安装必需模组。

可选：Forge 使用 Jade 11+、NeoForge 使用 Jade 15+ 显示信标信息。
